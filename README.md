📘 DVLD – Driving License Management System
Full Real-World Desktop Application | C# • OOP • SQL • ADO.NET • 3-Tier Architecture

🔹 Overview
DVLD is a full-scale, production-style desktop application that simulates a real Driving License Authority system.
The project focuses on building a complete, realistic system, applying programming concepts at real-world scale rather than small demos.

This project represents the transition from learning programming fundamentals to building enterprise-level software.

🧱 Architecture
3-Tier Architecture
Presentation Layer (UI)
Business Logic Layer (BLL)
Data Access Layer (DAL)
Clear separation of responsibilities
Clean, maintainable, and scalable structure

🛠️ Technologies Used
C# (Object-Oriented Programming)
SQL / T-SQL
ADO.NET
Windows Desktop Application
Basic security practices (validation & hashing)

🔑 Key Features
User authentication & role-based permissions
People & users management
Driving license issuance, renewal, and replacement
Lost/damaged license handling
License detainment & release
Local & international driving licenses
Reports, history tracking, and validations

🗄️ Database
Fully designed relational database
Proper table relationships & constraints
Business rules enforced at application and database levels

🎯 What This Project Demonstrates
Real-world application of OOP at scale
Clean architecture & layered design
Practical database integration using ADO.NET
Experience working on large, realistic systems
Strong problem-solving and system thinking skills

🚀 Outcome
This project strengthened my ability to design, build, and maintain enterprise-style backend systems and prepared me for advanced backend and real-world development.
